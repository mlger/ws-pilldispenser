PillDispenser Firmware

Browser-based installer for the Waveshare ESP32-S3-Touch-LCD-4.3B.

Install firmware

Web Serial is not available in this browser.

Channel builds are generated from tagged releases in Phase 6; until then this page is a placeholder (docs/web-flasher.md).

Browser support

Supported: desktop Chrome/Edge 89+, Opera, Firefox 151+ desktop (Web Serial permission), Chrome for Android 148+ (USB-OTG, best effort).
Not supported: Safari (macOS/iOS), Firefox for Android — use the command-line fallback below.

Command-line fallback (merged image)

esptool.py --chip esp32s3 --port /dev/ttyUSB0 --baud 921600 \
  write_flash 0x0 pd-main-<version>-dev-merged.bin

The merged image is flashed at address 0x0, matching the Waveshare procedure. Never use the merged image to update a configured device — it would overwrite NVS (0x9000).

Putting the board into download mode

  1. Use the USB-C port labelled UART (auto-download circuit) with a data-capable cable; close any serial monitor.
  2. Click Connect & Install and pick the serial port.
  3. If the port does not appear: unplug the board (and the 7–36 V supply / battery), hold BOOT, plug USB in, release BOOT, then retry.
  4. After flashing, press RESET (download mode is not exited automatically).
  5. Linux: add your user to the dialout group. macOS: install the USB-UART driver if the port is missing.

Privacy

This page is static. It collects no data and never touches device eFuses.
